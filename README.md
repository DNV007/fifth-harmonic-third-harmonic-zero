```bash
uv sync                                              # pinned environment, from uv.lock
JAX_ENABLE_X64=1 uv run pytest -q                    # 61 tests, ~6.5 min

```

Run everything **from the root of this deposit**. `run_all.py` executes the 39
drivers behind the manuscript and its Supplemental Material in dependency order, and
takes a few hours end to end because several continuations are individually slow
(see [Runtimes](#runtimes)).

To check one number rather than all of them, use **`reproduce.md`**: it maps
every figure, table, section, and quoted value to the single driver that

## What the code does

A damped linear absorber keeps its amplitude minimum but loses its transmission
zero, which leaves the real-frequency axis. At a generated harmonic the
situation differs: the third harmonic carries no direct drive, so an exact zero
requires two real cancellations under two real controls. That condition has
codimension two, which is why a one-parameter frequency sweep reaches only a
minimum.

The leading fundamental-source balance supplies one of the two cancellations.
Absorber loss leaves a phase deficit of fixed sign, amplitude independent at
leading order, and what closes it is the orbit's own `5*Omega` motion returning
to `3*Omega` at weight `|Delta_1|^4`. The fifth harmonic carries `1.8e-3` of the
relative-coordinate fundamental, yet it decides whether the zero exists: a
homotopy that weights its `5*Omega -> 3*Omega` return below `0.48` annihilates
the tracked pair in a saddle-node. Because that channel ranks at `O(F^7)`
against an `O(F^3)` leading source, closure is unreachable at weak amplitude.

The code solves the periodic response of a damped nonlinear absorber by harmonic
balance, locates the third-harmonic zero, computes its local index and Floquet
spectrum, follows two opposite-index roots into a fold, runs the fifth-harmonic
homotopy, and recovers the same root from a continuous-time shooting solve that
uses no Fourier truncation. A second oscillator model with inertial coupling
repeats the test, with a negative control at a spectrally unselected zero of the
same equations.

Two limits are stated plainly here because they are stated plainly in the paper.
Reported `|X3|` values at a root are constrained-solver residuals at
termination, not physical null depths, and they rescale with the
nondimensionalization. The winding numbers are computed on sampled loops, not
interval enclosures, so they are numerical evidence for the local degree rather
than validated proofs.

## Install and run

Requires Python >= 3.11 (jax 0.10.2 does not support 3.10). With
[uv](https://docs.astral.sh/uv/):

```bash
uv sync
JAX_ENABLE_X64=1 uv run python scripts/run_k3_ode_shooting.py   # one driver
JAX_ENABLE_X64=1 uv run python scripts/run_all.py               # all of them
uv run pytest -q          # 61 tests, ~6.5 min
```

or with pip:

```bash
python -m pip install -e . pytest
JAX_ENABLE_X64=1 python scripts/run_k3_ode_shooting.py   # one driver
JAX_ENABLE_X64=1 python scripts/run_all.py               # all of them
pytest -q
```

Run drivers **from the root of this deposit**. Several write to `data/` and
`figures/` by relative path and will put their output in the wrong place
otherwise. Set `JAX_ENABLE_X64=1`; the constrained solves need double precision and are
meaningless without it.

The solves are deterministic and use no platform-specific constant or private
data. No reported number depends on a random seed. Several searches reported as
"no root found" were run from seed grids fixed inside their driver scripts;
their coverage therefore depends on those grids, which is why the paper reports
them as bounded evidence within a stated window rather than as nonexistence.

## Where to start

Three checks, in order of directness.

```bash
JAX_ENABLE_X64=1 uv run python scripts/run_k3_ode_shooting.py
```

This solves the continuous-time problem: periodicity of the time-`T` flow
together with `Re X3 = Im X3 = 0`, for the initial state and the two controls.
No Fourier truncation enters. It converges to `Omega = 0.259728097303`,
`beta1 = 0.238154276523`, agreeing with the harmonic-balance root to a relative `1e-9`,
with a nonsingular 6x6 Jacobian. The run also checks that the `y0` block of that
Jacobian plus the identity equals the monodromy matrix, and that
`det J = det(M - I) det J_red`.

```bash
JAX_ENABLE_X64=1 uv run python scripts/run_k3_winding_certificate.py
```

This evaluates the third-harmonic response on a loop around the working point
and returns the degree of the sampled map. A nonzero degree places a zero of the
converged harmonic-balance map inside the loop, independently of the residual
the solver reaches. Expected output is degree `+1` with `|X3|` on the loop some
five orders above the solver floor. The loop is sampled rather than
interval-enclosed, so this is evidence for the degree, not a validated proof.

```bash
JAX_ENABLE_X64=1 uv run python scripts/run_k3_multimethod_verification.py
```

This re-derives the root four ways: a complex-exponential FFT-Galerkin harmonic
balance that shares no code path with the production cosine-sine residual,
cold-start `Radau` and `LSODA` integrations, a 70x70 scan at `N_H = 7` with
augmented Newton refinement, and a 67x67 scan at `N_H = 3` where the root is
absent. Expect
agreement to `4e-11` between the two discretisations, `|X3|` at the integrator
floor, exactly two arms with control-Jacobian determinants of opposite sign, and
a minimum `|X3|` of `4.1e-6` at `N_H = 3`.

## Runtimes

Most drivers finish in seconds to a few minutes. These are slow, so run them in
the background:

| Driver | Time | Note |
|--------|------|------|
| `run_k3_main_figures.py` | seconds with cache, tens of minutes without | caches its 61x61 grid in `figures/k3_main_figures_cache.npz`; delete the cache to force a full re-solve |
| `make_k3_existence_figure.py` | seconds with cache, otherwise dominated by two full 2-D solves | caches both maps in `data/two_dof_k3_existence_maps.npz`; delete the cache to force a full re-solve |
| `run_k3_fifth_harmonic_homotopy.py` | minutes | pseudo-arclength continuation in the homotopy weight, through the fold |
| `run_k3_persistence_renull.py` | ~1 hour | augmented re-nulls plus a drive-plane grid |
| `run_k3_rlc_second_example.py` | ~4 minutes | re-acquires the second-model working point by warm-stepping the forcing |
| `run_k3_extended_model_persistence.py` | ~10 minutes | quintic ladder and mass-ratio legs |
| `run_k3_mean_mode_corrections.py` | ~15 minutes | repeats the quadratic and gate calculations with the mean modes carried |
| `run_k3_multimethod_verification.py` | ~13 minutes | dominated by the Radau and LSODA transients; the two scans take ~2.5 min together |

`run_k3_ode_shooting.py` takes about two minutes and needs no cache.

`run_k3_fold_F_free.py`, `run_k3_quintic_fold_F.py` and
`run_k3_weak_drive_route.py` repeat an augmented turning-point or
pseudo-arclength solve at every forcing on a grid, so each is substantially
slower than the corresponding single-point solve. Run them in the background and
read their CSV output rather than waiting on the terminal.

## Two standalone drivers

`run_k3_rlc_second_example.py` and `run_k3_extended_model_persistence.py` carry
their own harmonic-balance residual and share no code with
`src/hh_antiresonance/`. This is deliberate. The production parameter set
describes neither the inertially coupled second model nor a mass ratio and
quintic, so those
systems cannot be expressed in it. Each validates against the production path
where the models coincide: the extended model reproduces the production working
point to `3e-9` at unit mass ratio and zero quintic.

## The zero-frequency mode

The default basis carries harmonics `k = 1..N_H` and no mean term. That is exact
wherever the on-site quadratics vanish: the orbit is then half-period
antisymmetric, so both zero-frequency balances are satisfied identically, and
carrying the mean modes as free variables returns them at `3e-18`.

It stops being exact as soon as a quadratic term is present. Averaging the
equations of motion over one period leaves `alpha_1 <x1^2>`, which is strictly
nonzero and forces a static offset in both oscillators. Any calculation with
`alpha_j != 0` must therefore pass `include_mean=True`, and the electrostatic
gate path must also pass its constant force through `force_dc`:

```python
c = solve_harmonic_balance(p, n_harmonics=7, include_mean=True, force_dc=fdc)
a0_1 = c[mean_index(oscillator=1, n_harmonics=7)]
```

The two mean coefficients are appended after the `4*N_H` oscillatory ones, so
every index returned by `coefficient_index` is unchanged whether or not the mean
modes are carried. `run_k3_mean_mode_corrections.py` runs the two affected
calculations both ways and prints the difference.

## Scope

`scripts/`, `figures/` and `data/` carry exactly what backs the manuscript and its
Supplemental Material, and nothing else: the 39 drivers of `run_all.py`, the
figures as placed in the two documents, and the data those drivers write or
read. Every quantity reported in the manuscript and its Supplemental Material has a
driver here, and the values printed in the paper are the ones these drivers
produce. Earlier exploratory campaigns are not part of this deposit. `src/` is
shipped whole because it is one importable package.
